# 🚀 Тутор: автозапуск `no_ui.bat` в Windows

Нижче два простих способи зробити автозапуск файлу:
`C:\cd_v2_script\no_ui.bat`

---

## Спосіб 1 (рекомендовано): папка «Автозавантаження»

1. Натисни `Win + R`.
2. Введи команду:
   ```
   shell:startup
   ```
3. Відкриється папка автозавантаження поточного користувача.
4. У цій папці натисни правою кнопкою → **Створити → Ярлик**.
5. У поле «Вкажіть розташування об’єкта» встав:
   ```
   C:\cd_v2_script\no_ui.bat
   ```
6. Натисни **Далее** → задай имя (например, `ConsoleDeck No UI`) → **Готово**.
7. Перезавантаж ПК і перевір, що скрипт запускається автоматично.

> Якщо не спрацювало: перевір, що файл справді лежить за шляхом `C:\cd_v2_script\no_ui.bat`.

---

## Як перевірити, що автозапуск працює

- Вийди з облікового запису і зайди знову, або перезавантаж ПК.
- Перевір, чи стартує потрібний процес/скрипт.
- Якщо потрібно, додай у `no_ui.bat` лог:
  ```bat
  echo started %date% %time% >> C:\cd_v2_script\startup_log.txt
  ```
  Так буде видно, чи запускався `.bat` після входу в систему.

---

## Часті проблеми

- **Путь указан с `/` вместо `\\`**  
  Для Windows краще використовувати:
  `C:\cd_v2_script\no_ui.bat`
- **Скрипт не запускається при старті**  
  Запусти `no_ui.bat` вручну подвійним кліком і переконайся, що він працює без помилок.
- **Вікно консолі заважає**  
  Використай розділ нижче: **«Міні-гайд: прихований запуск через VBS»**.

---

## Міні-гайд: прихований запуск через VB

- Запусти `run_hidden.vbs` подвійним кліком: вікно консолі не повинно з’являтися.
- Якщо скрипт не стартує, тимчасово заміни параметр `0` на `1`:
  ```vbscript
  WShell.Run Chr(34) & "C:\cd_v2_script\no_ui.bat" & Chr(34), 1
  ```
  Так вікно буде видно і простіше зрозуміти, де помилка.
- Після того як зрозуміли, що скрипт працює, зроби дії вище, але з цим файлом.
